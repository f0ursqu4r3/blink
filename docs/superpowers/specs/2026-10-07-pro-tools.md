# Pro tools

Build five extensions to the existing native application:

- Inspect resolved sends, credential/token sources, cookies, redirect destinations, HTTP version and available TLS metadata. Redact credentials by default. State transport visibility limits.
- Run a group in order with existing assertions and captures. Support stop-on-failure, failed-case reruns, CSV/JSON rows and a headless project runner with CI exit codes.
- Store named secrets in the OS credential store. Add browser OAuth PKCE with refresh and host-scoped client certificate identities. Keep secret values out of project files.
- Compare JSON fields, ignore selected paths, retain a local baseline and compare history entries across environments. Keep text comparison for other bodies.
- Retain OpenAPI source/operation context. Offer parameters and examples, report missing required inputs and response schema issues, and reload source files with change reporting.

Preserve local groups, disk-backed projects, existing edits, request cancellation and protected environment checks. Never report unavailable protocol details or unsupported schema checks as verified. Use focused modules and local temporary data in tests.
