# Pro Tools Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement each owned task. Independent modules use the parallel-agent skill.

**Goal:** Make the five remaining professional workflows usable in the native app.

**Architecture:** Reuse Engine, Workspace, send checks and history. Keep transport/security helpers in core and add small GPUI panels. Store private configuration and comparison state locally; only OpenAPI operation metadata travels with drafts.

**Tech Stack:** Rust, GPUI Kit, reqwest, serde, macOS Security framework.

**Spec:** docs/superpowers/specs/2026-10-07-pro-tools.md

## Global Constraints

Preserve all existing uncommitted edits. Do not commit. No live service credentials in tests. Honor file grants and protected environments. Do not write credentials into shared project documents.

## Review Focus

Dataset precedence and captures must not cross iterations. Secret resolution must not disclose values in errors. Redirect tracing must preserve the existing redirect policy. JSON comparison must distinguish absent fields and null. OpenAPI validation must report unresolved references and unsupported schema constraints.

## Tasks

- [x] Collection execution: create core collection_runner.rs, src/bin/blink-run.rs, store/collection_runner.rs and ui/collection_runner.rs. Expose ordered run reports and dataset parsing. Test row boundaries, failed assertions, stop/cancel and CI statuses. Attach group menu action.
- [x] Structured comparisons: create core response_comparison.rs and extend ui/history_view.rs. Test JSON key order, missing/null, arrays and ignored subtrees. Persist local baseline independently of history pruning.
- [x] OpenAPI: create core openapi_contract.rs and ui/contract_panel.rs; extend import.rs and Draft optional metadata. Test local refs, required parameters and response mismatch. Attach request Contract tab.
- [x] Authentication: create core credentials.rs and engine authentication module; create UI credentials panel. Test PKCE/state parsing, secret references, redaction and host matching. Use OS credential store for secret values and certificate identities.
- [x] Request inspection: capture request metadata in transport and show it in Response panel. Test redaction and redirect traces with local HTTP fixtures.
- [x] Integration: run cargo fmt, focused tests, workspace tests and clippy. Review diff for storage compatibility, secret disclosure and UI access. Update README and PRODUCT with exact capabilities and limits.

Shared module registration, model fields and integration hooks belong to the primary agent. Workers own the isolated module files listed above.

Validation: workspace tests, formatting, diff whitespace and Clippy with the pre-existing GraphQL needless_late_init lint excluded. Local HTTPS integration tests cover PKCE exchange, refresh rotation, concurrent refresh, cancellation, removal, token errors and client-certificate origin restrictions. Live provider login and OS Keychain authorization remain manual checks; automated tests use an in-memory credential store and never access real credentials.
